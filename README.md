# CodeGym Career – Material Design Landing Page

Bài tập: Xây dựng Landing Page theo phong cách Material Design.

## Nội dung

Landing Page sử dụng nội dung tham khảo từ trang CodeGym Career:
https://codegym.vn/codegym-career/

Các phần chính:
- Navbar responsive
- Hero section
- Tổng quan chương trình
- Lợi ích / giá trị cốt lõi
- Lộ trình ứng tuyển
- Khóa học CGC Java / CGC PHP
- Hệ thống hỗ trợ học tập
- Form CTA đăng ký tư vấn
- Footer

## Công nghệ

- HTML5
- CSS3
- JavaScript
- Bootstrap 4.5
- MDBootstrap 4.19.1
- Font Awesome 5
- Google Fonts Roboto

## Chạy bài

Mở `index.html` bằng trình duyệt hoặc dùng Live Server trong VS Code.

## Lưu ý

Form đăng ký chỉ là demo giao diện. Khi submit, JavaScript hiển thị thông báo thành công tại chỗ và không gửi dữ liệu tới CodeGym.

Nội dung số liệu/chương trình được tham khảo từ trang nguồn tại thời điểm thực hiện bài tập; không nên hiểu landing page này là trang chính thức của CodeGym.
